# 猫娘 API 排错更新（2026-09-27）

当前接口协议为 OpenAI Chat Completions，不是 Claude 原生 Messages。

## 用户操作

刷新页面 → 右侧「与猫娘对话」→「检测连接」。
检测仅请求保存的 API 服务的模型列表，不发送聊天记录，不生成回复。
检测成功不能保证实际生成成功，仍需发送消息验证。

- CONNECTION_OK：连接、鉴权成功，并在模型列表中发现配置的模型。
- MODEL_NOT_LISTED：鉴权成功，但未发现配置的模型名。
- MODEL_LIST_UNAVAILABLE：服务商未开放 /models，不代表 /chat/completions 不可用。
- DNS_CHECK_FAILED：两个 DNS 检查服务均不可用，还未发送请求到模型。
- DNS_PRIVATE：域名解析到非公网地址，为保护密钥已阻止请求。
- API_HTTP_401：服务商拒绝密钥。
- API_HTTP_403：权限、地区或防火墙拦截。
- API_HTTP_429：服务商额度/限流问题。
- API_CONNECT_FAILED：Cloudflare 到服务商的网络或 TLS 连接失败。
- API_TIMEOUT：模型请求最长 90 秒仍未收到完整响应。
- API_REDIRECT：服务商跳转地址；为保护密钥，不自动转发 Authorization。

失败消息旁的「重试这条消息」必须由用户主动点击，并复用原记录。
重试会再次请求服务商，可能计费；后端不自动重试生成请求。
旧聊天中的历史报错保留，不会因新版本上线自动变成成功回复。

## 改动

- DNS 检查由单一 Cloudflare DoH 改成 Cloudflare / Google DoH 回退，仍然拒绝非公网地址。
- 模型等待从 30 秒延长到 90 秒，锁定与挂起记录恢复时限相应延长。
- 存储错误阶段、错误码和随机追踪号；不记录明文密钥、聊天正文或原始服务商错误正文。
- 修复失败后草稿被清空；增加主动重试、检测连接和挂起状态轮询。
- 基础域名自动补 /v1；已有路径保留，不擅自改写网关前缀。

## 测试范围

30 项单元测试通过，覆盖 DNS 回退、超时、重定向防泄露、错误分类、只读检测等。
tests/nyan-ui.mjs 使用本地 Worker + D1 和无效测试密钥验证失败流程；
成功提示的 UI 验证使用明确标记的 HTTP 测试夹具，不等于真实服务商生成成功。
本次未使用玩家的有效密钥生成付费回复，未修改玩家 API 配置。
